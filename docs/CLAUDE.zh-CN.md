# 用 Claude API 运行 SuperX（fork 新增功能）

English: [Claude API Key in the connection guide](CONNECTIONS.md#claude-api-key)

这个 fork 在原有的三种 Grok 连接方式之外，新增了第四种：**Claude API Key**。它使用你自己的 Claude API 额度，比如 Claude Max 订阅每月附带的 $100 API 额度。

默认设置面向偶尔核查、希望结果可信、不想被意外扣费的读者。需要大量核查的用户不必换一套模式，在设置里调高模型、搜索次数和触发方式即可。

## 默认设置

| 项目 | 默认 | 说明 |
| --- | --- | --- |
| Claude 模型 | Haiku 5.5（固定） | 「自动」需要自己选择，不会成为默认值。 |
| 推理档位 | 中 | 可改为低或高。 |
| 每次核查最多网页搜索次数 | 3 | 每次搜索约 $0.01，另计 Token。 |
| 每个周期的花费上限 | $100 | 填 0 表示不限制。 |
| 每月重置日 | 15 号 | 请改成你的额度到期日。 |
| 触发方式 | 新安装：只在点击时核查 | 已有用户的触发设置保持不变。 |
| Claude 自动核查 | 关闭 | 勾选「也允许自动核查」后才会自动核查。 |
| 回答缓存 | 1 天，保存在本机 | 关闭「保存浏览历史」时，只保留到关闭浏览器。 |
| 结论行和来源标签 | 始终显示 | 没有开关。 |
| 本机免费预筛 | 对所有连接方式的自动触发开启 | 手动点击从不预筛。 |

## 使用前提

- 额度要在 **Claude Console**（platform.claude.com）里，也就是 Billing → Promotional credits（账单 → 促销额度）中能看到的那一笔。Claude Pro/Max 的聊天用量不能给第三方插件使用。
- Max 订阅的月度 API 额度**不能留到下个周期**，到期作废。额度用完后，如果没有添加付款方式或开启自动充值，Anthropic 会直接停止请求，不会扣你的卡。

## 设置步骤

1. 在 Claude Console 中，进入**持有额度的那个组织**，在 API Keys 页面创建一个 Key（以 `sk-ant-` 开头）。建议单独为 SuperX 创建一个，方便查看用量。
2. 打开 SuperX **设置 → 连接方式**，选择 **Claude API Key**，粘贴 Key 后保存。Key 用 AES-GCM 加密后只保存在本机。新安装时弹出的「设置向导」也可以完成这一步，之后可在设置或弹出窗口中重新打开。
3. 按需调整上表中的 Claude 模型、推理档位、搜索次数、花费上限和重置日。

## 触发方式

选 Claude 时，**默认只有点击帖子上的 SuperX 按钮才会核查**，刷到帖子不会自动核查。想要自动核查，可以勾选「也允许自动核查」。你保存的 Grok 触发设置不受影响，切回 Grok 时照常生效。

草稿核查（发帖或回复编辑框旁边的 SuperX 按钮）本来就是手动触发的，Claude 模式下照常可用。

## 预筛与「自动」模型

- **本机免费预筛**：自动触发的帖子如果过短、只有表情，而且没有图片、引用、链接或被折叠的正文，就不会发送请求。这类帖子显示「无可核查说法」（空心圆点），旁边有「仍要核查」。适用于所有连接方式，不产生任何费用。
- **自动核查前先预判**（默认开启，只在同时开启 Claude 自动核查时生效）：先用 Haiku 5.5 判断帖子是否包含可核查的事实陈述，每次不到 $0.001。不包含的帖子不会自动核查，同样可以点「仍要核查」。
- **Claude 模型选「自动」**（需手动选择）：先用 Haiku 快速预判，有争议、高风险或难以判断的帖子用 Sonnet 5.5，其余用 Haiku 5.5。回答的用量提示中会注明选择了哪个模型以及原因。预判失败时一律用 Haiku，不会因此多花钱。
- 预判费用计入同一个周期花费；手动点击的核查和草稿核查不会被预判拦下。

## 结论行与核查范围

- 每条回答顶部有一行结论：准确、不准确、部分准确、证据不足或无可核查说法，用小圆点表示，不用彩色色块。
- 核查没覆盖到的部分会单独注明：未读到全文、未读取图片、未观看视频、未搜索，以及（Claude）未打开链接。
- 引用的网页按网址标注来源类型（官方、学术、新闻、参考资料、社交媒体、其他）。标签只看网址，不评价页面内容；没有引用官方、学术或新闻来源时会提示。

## 花费估算

- 每次请求结束后，SuperX 会根据返回的 Token 数和搜索次数，按官方价格估算花费，并累计到「本周期已用」。
- 累计金额达到上限后，新的 Claude 请求会被拦下，提示「已达到本周期的 Claude 花费上限」。
- 这只是**估算**，实际用量和余额以 Claude Console 为准。
- 粗略参考：Haiku 5.5 每次核查约 $0.02～0.03，大部分花在搜索上；Sonnet 5.5 约 $0.07；Opus 5.5 约 $0.12。
- 复用缓存中的回答不产生费用。设置 › 维护与排障 中会显示复用次数和约节省的金额。

## 和 Grok 的区别

- Claude 能搜索网页，但**没有 X 搜索**，也打不开 x.com 的帖子页面。SuperX 会把你屏幕上的内容一并提供给 Claude：帖子正文、引用帖、图片描述、链接卡片和社区笔记。
- Claude 还可以打开帖子自带的链接（每次最多两个），`x.com`、`twitter.com` 和 `t.co` 不在可打开范围内。SuperX 不会替你点开「显示更多」，也不抓取整条讨论串；正文被折叠时，结论行会注明「未读到全文」。

## 技术说明

- `extension/claude-transport.js`：把共用的核查提示词转换成 Claude Messages API 的请求格式，解析流式返回，构造预判请求，并估算花费。
- `extension/api-provider.js` 的 `runClaudeStage` 负责一次 Claude 核查。重试、保留部分答案、语言检查和历史记录等逻辑都和 Grok 共用。
- `extension/provider-registry.js` 描述每种连接方式的名称、链接、能力和缓存规则，新增连接方式的方法见 [PROVIDERS.md](PROVIDERS.md)。
- 请求直接从扩展的后台发往 `https://api.anthropic.com/v1/messages`，所以 `manifest.json` 增加了这个域名的访问权限。数据说明见 [隐私说明](../PRIVACY.md)。
- 测试：`tests/claude-provider.test.js`、`tests/triage.test.js`、`tests/verdict.test.js` 等；离线评测见 [EVAL.md](EVAL.md)。
